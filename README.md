# 🎙 Elbek Studiya Minus Bot

Telegram bot: **[@ElbekStudiyaMinusbot](https://t.me/ElbekStudiyaMinusbot)**

---

## 📌 Botning asosiy imkoniyatlari:

1. **🔎 Qidiruv:**
   - Foydalanuvchi san'atkor ismini (masalan: `Jaloliddin`, `Yulduz`, `Ozodbek`, `Doxxim`) yoki qo'shiq nomini yozadi.
   - Bot bazadagi barcha mos keluvchi minuslarni qidirib topadi va tugmalar ko'rinishida chiqaradi.
   - Foydalanuvchi tugmani bossa, bot audioni to'g'ridan-to'g'ri yuboradi.

2. **🎤 San'atkorlar ro'yxati:**
   - Bazadagi barcha san'atkorlar va ularning minuslari soni ro'yxat bo'lib chiqadi.

3. **⭐️ Sara minuslar:**
   - Eng ko'p yuklab olingan top minuslar ro'yxati.

4. **👑 Admin Paneli:**
   - Yangi minus audio fayllarni oson yuklash (audio yuboriladi, bot avtomatik yoki qo'lda san'atkor va qo'shiq nomini kiritadi).
   - Minuslarni o'chirish.
   - Barcha foydalanuvchilarga xabar tarqatish (Broadcast).
   - To'liq statistika (foydalanuvchilar, minuslar, san'atkorlar, yuklab olishlar).

---

## 🔑 Admin bo'lish yo'riqnomasi:

1. Telegram'da **[@ElbekStudiyaMinusbot](https://t.me/ElbekStudiyaMinusbot)** ga kiring va `/start` bosing.
2. Botga **/admin** buyrug'ini yuboring.
3. Bot maxfiy parol so'raydi. Quyidagi parolni yuboring:
   `elbek_admin_2026`
4. Shundan so'ng siz avtomatik tarzda **Admin** bo'lasiz va botda Admin Panel tugmalari paydo bo'ladi.

---

## 🎧 Yangi minus qo'shish tartibi (Admin uchun):
1. Admin menyusidan **➕ Yangi minus qo'shish** tugmasini bosing.
2. Minus audio faylini (mp3) botga yuboring.
3. Bot sizdan san'atkor ismini so'raydi (masalan: *Jaloliddin Ahmadaliyev*).
4. Keyin qo'shiq nomini so'raydi (masalan: *Janonim*).
5. Tayyor! Qo'shiq darhol bazaga kiritiladi va barcha foydalanuvchilar qidirganda topa olishadi.

---

## 🚀 Botni qayta ishga tushirish (agar kompyuter o'chib yonsa):
Bot papkasidagi **`run_bot.bat`** faylini sichqoncha bilan ikki marta bossangiz, bot darhol qayta ishga tushadi.
